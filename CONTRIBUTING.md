# Contributions

QwenOC accepts contributions.

## Before you start

- Read the [README](README.md) and the `docs/` documentation.
- Open an issue for a problem or a new feature before a large change.
- Do not open an issue for a security problem. See [SECURITY.md](SECURITY.md).

## Do the work

- Keep the repository structure. Each launcher, config, and plugin has one task.
- Use ASD-STE100 Simplified Technical English, Issue 9, for new or changed English documentation.
- Start `make ci` before you send your change. It does the lint and the tests.

## Send your change

- Send a pull request to the `master` branch. Make the pull request ready for review.
- When you send a contribution, you give Vadym Temirov the rights in [CONTRIBUTOR_LICENSE.md](CONTRIBUTOR_LICENSE.md).
